# Mangux Ofimática

## Descarga el launcher

**[⬇ Mangux Ofimática (launcher) 0.1.1 — APK para Android](https://github.com/Dannyaviles99/Mangux-Oficematica/releases/download/launcher-v0.1.1/launcher-0.1.1-2.apk)**

Es lo único que necesitas instalar. Al abrirlo escribe tu llave y tu código de activación; desde dentro instalas y actualizas Mangux Leaf, Xcore, Prism y Seal.

1. Instala el APK. Android pedirá permitir «Instalar apps desconocidas» para el launcher (una vez).
2. Abre Mangux Ofimática y escribe la llave y el código de activación.
3. Instala las aplicaciones desde el launcher. Las actualizaciones aparecen solas.

Las aplicaciones sueltas no funcionan sin el launcher y su licencia.

## Contenido del repositorio (sin código fuente)

| Archivo | Qué es |
|---|---|
| Releases `launcher-v…`, `worddroid-v…`, … | Los APK firmados. |
| `versions.json` | Catálogo: versión, enlace, tamaño, SHA-256, firmante y notas de cada app. |
| `versions.json.sig` | Firma Ed25519 del catálogo; el launcher rechaza uno que no coincida. |
| `notes/` | Notas de versión. |
